What is this?
This simulator mimics a modified Instagram wrapper. When enabled, it visually removes the Reels and Explore tabs, preventing doom-scrolling.

How to do this for real

You can achieve this effect on your real phone by using Instagram in a Mobile Browser (Safari/Chrome) and running this script.

Tip: Create a new bookmark in your browser, paste the code below as the URL, and tap it whenever you open Instagram.
Copy this Bookmarklet Code: 
javascript:(function(){
    const style = document.createElement('style');
    style.innerHTML = `
      /* Hide Reels Tab */
      a[href*="/reels/"], [aria-label="Reels"] { display: none !important; }
      
      /* Hide Explore Tab */
      a[href*="/explore/"], [aria-label="Explore"], [aria-label="Search"] { display: none !important; }
      
      /* Optional: Hide Main Feed Posts but keep Stories */
      /* Remove the comment markers below to hide feed */
      /* article { display: none !important; } */
    `;
    document.head.appendChild(style);
    alert('Focus Mode Activated! Reels and Explore hidden.');
  })();
